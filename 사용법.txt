Claude Code 설치 마법사 - 사용법
==================================

이 마법사로 할 수 있는 것
  1. Claude Code(말로 부탁하면 프로그램을 만들어주는 AI 도우미)를 설치하고 로그인합니다.
  2. Claude Code에게 부탁해서 "매일 아침 환율·코스피 요약 메일" 프로그램을 만듭니다.
  3. 매일 정해진 시각에 저절로 메일이 오도록 예약합니다.

걸리는 시간: 약 30~40분
명령어를 직접 칠 일은 없습니다. 버튼 누르기와 복사·붙여넣기(Ctrl+V)만 씁니다.


준비물
  [ ] Windows 10 또는 11 컴퓨터
  [ ] 인터넷 연결
  [ ] Claude 유료 구독 계정 (Pro 또는 Max)
  [ ] Gmail 계정 + 문자를 받을 휴대폰 (2단계 인증용)


시작하는 방법
  1. 받은 zip 파일을 마우스 오른쪽 버튼으로 누르고 [압축 풀기]를 누릅니다.
     (zip 안에서 바로 실행하면 안 됩니다. 꼭 압축을 먼저 풀어주세요.)
  2. 압축을 푼 claude_setup_wizard 폴더 안의 start.bat 을 더블클릭합니다.
  3. "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] -> [실행]을 누릅니다.
     (인터넷에서 받은 프로그램이라 뜨는 안내입니다.)
  4. 검은 창이 뜨고, 잠시 뒤 브라우저에 마법사 화면이 열립니다.
     - 검은 창은 닫지 말고 그대로 두세요. 닫으면 마법사가 꺼집니다.
     - Node.js가 없는 PC라면 설치 안내 화면이 먼저 열리고 자동 설치가 시작됩니다.
       "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?"가 나오면 [예]를 누르세요.
  5. 화면의 1~5단계를 순서대로 따라갑니다. 막히면 각 단계의 [막혔어요] 버튼을 누르세요.


단계 요약
  1단계 설치      [Claude Code 설치하기] 버튼 한 번. 1~3분.
  2단계 로그인    [로그인 창 열기] -> 브라우저에서 Claude 로그인 -> [승인]
  3단계 Gmail     구글에서 "앱 비밀번호"(16자리)를 받아 붙여넣고 [저장하고 확인]
  4단계 자동화    [요청 문장 복사] -> 검은 창에 Ctrl+V -> Enter -> 기다리기
  5단계 예약      시각을 고르고 [매일 자동 실행 등록]

  각 단계가 끝나면 화면이 5초 안에 알아서 초록 체크를 표시하고 다음 단계로 넘어갑니다.


꼭 알아두세요
  - 매일 메일은 PC가 켜져 있어야 보내집니다. 꺼져 있었다면 다음에 켜고 로그인할 때 한 번 보냅니다.
  - Gmail 앱 비밀번호는 이 PC의 agent\.env 파일에만 저장됩니다. 다른 사람에게 이 파일을 보내지 마세요.
  - 마법사를 다시 열려면 start.bat 을 다시 더블클릭하면 됩니다. 하던 곳부터 이어집니다.


자주 묻는 질문 (10가지)

  Q1. start.bat을 더블클릭했는데 파란 경고창이 떠요.
      [추가 정보]를 누른 뒤 [실행]을 누르세요. 서명되지 않은 프로그램이라 뜨는 안내입니다.
      "열려 있는 파일 - 보안 경고" 창이 뜨는 PC도 있습니다. 그때는 [실행]을 누르세요.

  Q2. 검은 창이 잠깐 떴다가 바로 사라져요.
      zip 안에서 바로 실행했을 가능성이 큽니다. 압축을 먼저 풀고, 풀린 폴더의 start.bat을 실행하세요.

  Q3. 설치가 끝났다는데 계속 "아직 안 함"으로 나와요.
      컴퓨터가 새 프로그램을 아직 못 알아본 것입니다. 검은 창을 닫고 start.bat을 다시 실행하세요.
      그래도 같으면 PC를 다시 시작하세요.

  Q4. 로그인할 때 브라우저가 안 열려요.
      검은 창에 보이는 https:// 로 시작하는 주소를 마우스로 드래그해 선택하고,
      마우스 오른쪽 버튼으로 복사한 뒤 브라우저 주소창에 붙여넣으세요.

  Q5. 무료 Claude 계정으로도 되나요?
      아니요. Claude Code는 Pro 또는 Max 유료 구독이 필요합니다.

  Q6. Gmail "앱 비밀번호" 메뉴가 안 보여요.
      2단계 인증을 먼저 켜야 메뉴가 생깁니다. 회사/학교 계정은 막혀 있을 수 있으니 개인 Gmail을 쓰세요.

  Q7. "Gmail 로그인이 거절됐어요 (535)"가 나와요.
      평소 비밀번호를 넣었거나 앱 비밀번호가 틀린 경우입니다. 앱 비밀번호를 새로 만들어 다시 저장하세요.

  Q8. 테스트 메일이 안 와요.
      스팸함과 프로모션 탭을 확인하세요. 4단계 [테스트 메일 보내기]에서 오류가 나오면
      [고쳐달라고 요청 복사]를 눌러 Claude Code 창에 붙여넣으세요.

  Q9. 매일 아침 검은 창이 잠깐 떴다 사라져요.
      정상입니다. 예약된 프로그램이 실행되는 모습입니다.

  Q10. 이제 그만 받고 싶어요. 어떻게 지우나요?
      마법사 5단계에서 [예약 해제]를 누르세요. 그다음 claude_setup_wizard 폴더를 통째로 지우면 됩니다.
      Claude Code까지 지우려면 Claude Code 공식 안내(claude.com/claude-code)를 참고하세요.


문의할 때
  문제가 생기면 마법사 화면 빨간 상자의 [자세히 보기]를 눌러 나온 내용을 함께 알려주세요.
  (비밀번호는 자동으로 가려집니다.)
