# Windows 실기 확인 체크리스트

클라우드(리눅스)에서는 Windows 동작을 확인할 수 없어서, 아래 항목은 실제 Windows PC에서 확인이 필요합니다.
**새 Windows 사용자 계정**을 하나 만들어서 진행하면 "처음 쓰는 사람" 상태를 가장 비슷하게 재현할 수 있습니다
(설정 → 계정 → 가족 및 기타 사용자 → 다른 사용자 추가 → "이 사람의 로그인 정보 없음" → "Microsoft 계정 없이 사용자 추가").

결과는 각 칸에 ✅ / ❌ 와 메모로 적어주세요. ❌ 항목은 화면 사진과 빨간 상자의 [자세히 보기] 내용을 같이 남겨주세요.

## 0. 준비

- [ ] `v*` 태그를 푸시하고 Actions의 "Release zip"이 성공했는지, Release(초안)에 zip이 붙었는지
- [ ] zip 안 구조가 `claude_setup_wizard/` 아래 `start.bat`, `server.js`, `사용법.txt`, `README.md`, `public/`, `.claude/settings.json` 인지 (`agent/`, `.env` 없음)
- [ ] 탐색기에서 zip을 열었을 때 `사용법.txt` 이름이 깨지지 않는지
- [ ] `사용법.txt`를 메모장으로 열었을 때 한글이 깨지지 않는지

## A. Node.js가 없는 PC (새 사용자 계정 + Node 미설치)

> Node가 이미 깔린 PC라면 "앱 및 기능"에서 Node.js를 제거한 뒤 진행하세요.

1. [ ] zip을 [다운로드] 폴더에 받고 마우스 오른쪽 → [압축 풀기]
2. [ ] `start.bat` 더블클릭 시 뜨는 경고 종류 기록 (SmartScreen "PC 보호" / "보안 경고" / 없음) — 사용법.txt Q1 문구와 맞는지
3. [ ] 검은 창의 영어 안내가 깨지지 않는지 (한글이 없어야 정상)
4. [ ] 브라우저에 **Node.js 설치 안내(한국어) 페이지**가 자동으로 열리는지
5. [ ] winget 설치 중 UAC(사용자 계정 컨트롤) 창이 뜨는지, [예] 후 1~3분 안에 끝나는지
6. [ ] 설치 후 **start.bat을 다시 실행하지 않아도** 이어서 마법사가 켜지는지 (`%ProgramFiles%\nodejs`를 PATH에 붙여서 계속 진행하도록 했음)
   - 안 되면: 검은 창의 마지막 메시지 기록
7. [ ] winget이 없는 PC(LTSC 등)에서: "winget not found" 메시지 + 안내 페이지의 nodejs.org 수동 설치 → start.bat 재실행으로 진행되는지
8. 이후 B의 3번부터 동일하게 진행

## B. Node.js가 있는 PC (새 사용자 계정)

### 시작
1. [ ] `start.bat` → 브라우저가 `http://127.0.0.1:5055`로 자동으로 열리는지
2. [ ] 검은 창의 한국어 안내("이 검은 창은 닫지 말고…")가 깨지지 않고 보이는지 (Node가 출력)
3. [ ] 시작 화면: 체크 4개를 모두 해야 [시작하기]가 켜지는지, 새로고침해도 체크가 유지되는지
4. [ ] 진행 막대가 항상 위에 고정되어 보이는지, 오른쪽 위 "5초마다 자동 확인 중 · 시각"이 계속 바뀌는지

### 1단계 설치
5. [ ] [Claude Code 설치하기] → 진행 중(스피너, 경과 시간) → 1~3분 뒤 **자동으로 초록 체크 + 다음 단계로 이동**
6. [ ] UAC 창이 뜨지 않는지 (관리자 권한 불필요 확인)
7. [ ] 설치 후 PATH 미갱신 상태에서도 "설치됨"으로 인식되는지 (`%APPDATA%\npm\claude.cmd`를 직접 찾도록 했음)
8. [ ] (가능하면) 와이파이를 끄고 설치 → "인터넷 연결에 문제가 있어요" 빨간 상자 + [자세히 보기]에 npm 원문이 보이는지
9. [ ] [막혔어요] 펼침 항목 5개가 열리는지

### 2단계 로그인
10. [ ] [로그인 창 열기] → 새 명령 프롬프트 창이 **마법사 폴더에서** 열리고 **claude가 저절로 실행**되는지
    - 폴더 경로에 한글/공백이 있는 경우(예: `C:\Users\홍길동\Downloads\...`)도 확인
11. [ ] 테마 선택 → 로그인 방법 → 브라우저 로그인 → "Login successful" 흐름이 화면 안내/예시 그림과 맞는지 (다르면 실제 문구 기록)
12. [ ] 로그인 직후 5초 안에 마법사가 **자동으로 초록 체크**로 바뀌는지 (`%USERPROFILE%\.claude\.credentials.json` 또는 `.claude.json` 확인 방식)
13. [ ] [실제로 확인하기] 버튼이 1~2분 안에 결과를 내는지

### 3단계 Gmail
14. [ ] 그림 안내의 링크 2개(2단계 인증, 앱 비밀번호)가 새 탭으로 열리는지
15. [ ] 16자리를 띄어쓰기 포함으로 붙여넣어도 "✓ 16글자"로 표시되고 저장되는지
16. [ ] [저장하고 확인] → "Gmail 로그인 확인 완료" 초록 표시
17. [ ] 일부러 틀린 앱 비밀번호 → **"Gmail 로그인이 거절됐어요 (535)"** 빨간 상자
18. [ ] 평소 비밀번호(16자 아님) → 저장 전에 "16글자여야 해요" 안내
19. [ ] 새로고침 후 비밀번호 칸이 비어 있고 "✓ 저장됨" 표시만 있는지, 빈 칸으로 다시 저장해도 기존 비밀번호가 유지되는지
20. [ ] `agent\.env` 파일이 생기고 내용이 맞는지 (메모장으로 확인)

### 4단계 자동화 만들기
21. [ ] [요청 문장 복사] → 검은 창 클릭 → `Ctrl+V` 붙여넣기가 되는지 (Windows 10 기본 콘솔 / Windows 11 터미널 각각)
22. [ ] Claude Code가 `agent\daily_market_agent.js`를 만들고 테스트 메일을 보내는지 (권한 질문에 1번 Yes)
23. [ ] Claude Code가 `agent\.env`를 **읽으려 할 때 거부**되는지 (`.claude\settings.json`의 deny 규칙)
24. [ ] 파일이 생기면 5초 안에 자동 초록 체크 + 다음 단계 이동
25. [ ] [테스트 메일 보내기] → 메일 수신, 실패 시 빨간 상자 + [고쳐달라고 요청 복사] 동작
26. [ ] 일부러 `daily_market_agent.js` 안에 오류를 넣고 실행 → "만든 프로그램 안에 오류가 있어요" 분류

### 5단계 예약
27. [ ] [매일 자동 실행 등록] → UAC 없이 등록되고 "예약됨: 매일 오전 7시" 표시
28. [ ] 작업 스케줄러(taskschd.msc)에 `ClaudeDailyMarket`이 보이고, 조건 탭의 "AC 전원일 때만 시작"이 **꺼져 있는지**, 설정 탭의 "예약된 시작 시간을 놓친 경우 가능한 대로 빨리 실행"이 켜져 있는지
    - "간단 방식으로 등록됨" 문구가 보이면 XML 등록이 실패한 것 → 그 PC 환경 기록
29. [ ] 2~3분 뒤 시각으로 바꿔 등록하고 실제로 메일이 오는지, `agent\last_run.log`에 기록되는지, 화면 "최근 실행 기록"에 보이는지
30. [ ] [지금 한 번 실행], [예약 해제] 동작 / 해제 후 작업 스케줄러에서 사라지는지
31. [ ] 한국어 Windows에서 schtasks 오류 메시지(예: 표준 사용자 계정의 정책 제한)가 깨지지 않고 [자세히 보기]에 보이는지

### 기타
32. [ ] 마법사가 켜진 상태에서 start.bat을 한 번 더 실행 → 새로 켜지지 않고 기존 화면이 열리는지
33. [ ] 다른 프로그램이 5055 포트를 쓰는 상태(예: `python -m http.server 5055`)에서 실행 → 5056번으로 켜지는지
34. [ ] 마법사 검은 창을 닫으면 화면 위에 "검은 창이 닫힌 것 같아요" 안내가 나오는지
35. [ ] 125%/150% 화면 배율, 브라우저 Edge/Chrome에서 글자·버튼이 잘리지 않는지
36. [ ] 노트북을 배터리 상태로 둔 채 예약 시각이 지나도 메일이 오는지

## 이 클라우드 검증에서 확인하지 못한 부분 (요약)

- start.bat 실제 동작(winget 설치, PATH 이어붙이기, UAC), SmartScreen 경고 종류
- 명령 프롬프트 창 띄우기(`start /D` + `windowsVerbatimArguments`)와 한글·공백 경로
- Windows에서의 Claude Code 설치 위치 탐지, 로그인 감지 파일 위치
- 작업 스케줄러 XML 등록(UTF-16, Principal/UserId), 예비 방식, 조회 결과 해석
- 한국어 Windows 출력(CP949) 해독 — 테스트는 바이트 단위로만 확인
- 실제 Gmail SMTP 로그인(테스트는 가짜 SMTP 서버로 235/535만 확인)
