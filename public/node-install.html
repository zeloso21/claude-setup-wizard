Node.js를 먼저 설치하고 있어요

Node.js는 이 마법사와 Claude Code가 돌아가는 바탕 프로그램이에요. 한 번만 설치하면 돼요.

① 자동 설치가 진행 중이라면 (검은 창에 "Installing Node.js…"가 보임)

  1. 1~3분 정도 기다려주세요. 검은 창은 닫지 마세요.
  2. 아래처럼 "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?" 창이 뜨면 [예]를 누르세요.
    사용자 계정 컨트롤
    이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?
    Node.js
    확인된 게시자: OpenJS Foundation
    예아니요
    왜 묻나요? Node.js는 이 PC의 모든 사용자가 쓰는 폴더(Program Files)에 설치되기 때문에 Windows가 한 번 허락을 받아요. 이 마법사에서 관리자 허락이 필요한 건 이 한 번뿐이에요.
  3. 설치가 끝나면 검은 창이 저절로 다음으로 넘어가고, 브라우저에 마법사 화면이 새로 열려요. 이 안내 탭은 닫아도 돼요.

② 검은 창에 "could not be installed" 또는 "winget not found"가 보인다면

직접 설치하면 돼요. 어렵지 않아요.

  1. 아래 버튼을 눌러 공식 사이트(nodejs.org)를 여세요.
    nodejs.org 열기
  2. 초록색 "LTS"라고 쓰인 다운로드 버튼을 누르세요(.msi 파일이 받아져요).
  3. 받은 파일을 열고 [Next] → [Next] → [Install] → [Finish] 순서로 누르세요. 중간에 허락을 물으면 [예].
  4. 마법사의 검은 창을 닫고, start.bat을 다시 더블클릭하세요.

설치했는데도 같은 화면이 다시 나오면 PC를 한 번 다시 시작한 뒤 start.bat을 실행해주세요. 새로 설치한 프로그램을 Windows가 알아차리는 데 재시작이 필요한 경우가 있어요.

회사 PC인가요?

회사 PC는 보안 정책 때문에 설치가 막혀 있을 수 있어요. 그럴 때는 전산 담당자에게 "Node.js LTS(nodejs.org) 설치"를 요청하세요.
