🪄 Claude Code 설치 마법사

터미널 명령어를 몰라도 괜찮습니다. 이미 설치된 항목은 자동으로 건너뛰고, 필요한 것만 순서대로 안내해드립니다. 마지막엔 실제로 동작하는 "이메일 섹터 리포트" 자동화까지 완성됩니다.

❓ "터미널"이 뭔가요? (컴퓨터가 처음이면 먼저 읽어보세요)
터미널은 마우스로 클릭하는 대신 글자를 입력해서 컴퓨터에게 직접 명령을 내리는 검은 화면이에요. 아래 단계들을 진행하다 보면 "터미널 열기"라는 버튼이 여러 번 나오는데, 그 버튼을 누르면 이 마법사가 알맞은 위치에 알아서 열어드리니 직접 찾아서 켤 필요는 없어요.
그래도 궁금하시다면: Windows에서는 키보드의 윈도우 키를 누르고 cmd라고 입력한 뒤 Enter를 누르면 "명령 프롬프트"라는 검은 창이 뜹니다 — 이게 터미널이에요. 처음 보면 아무것도 없는 새까만 화면이라 낯설 수 있지만, 이 마법사가 시키는 대로 문장만 그대로 입력하시면 되니 걱정 안 하셔도 됩니다.
⚠️ 주의: 이렇게 직접 연 터미널에 아직 아무것도 설치하지 않은 상태에서 바로 claude라고 쳐보면 'claude'은(는) 내부 또는 외부 명령... 이(가) 아닙니다라는 에러가 뜹니다 — 이건 컴퓨터가 고장난 게 아니라 아직 1단계 "Claude Code 설치"를 안 해서 나는 정상적인 메시지예요. 아래 1단계의 "자동 설치" 버튼을 먼저 눌러서 설치를 마친 뒤에 claude를 입력해야 동작합니다.
로컬 컴퓨터에서만 실행되는 도구입니다(Node.js 기반). 입력한 정보는 이 컴퓨터의 agent/.env 파일에만 저장됩니다.
